# Extended Meta Protocol для Counter-Strike 1.6

[English](README.md) | [Русский](README.ru.md)

Extended Meta Protocol (EMP) – плагин AMX Mod X, который публикует структурированные метаданные сервера через server cvar с префиксом `em_`. Мониторинги и другие сервисы могут получить эти значения стандартным запросом `A2S_RULES`.

- Версия плагина: `2026.0.15`
- Версия схемы протокола: `1`
- Автор: `Lagnetic Team`

## Возможности
Плагин позволяет публиковать следующие данные:

- Краткое описание сервера с безопасным делением на несколько строк.
- Игровой режим, ключевые слова, языки общения и интерфейса.
- URL иконки сервера и других изображений.
- Расширяемые ссылки и явно помеченные пользовательские метаданные.
- Опциональное обнаружение публичных команд AMX Mod X.

## Совместимость с AMX Mod X

| AMX Mod X | Поддержка | `em_updated` |
|---|---|---|
| 1.8.2 | Поддерживается | Не регистрируется |
| 1.8.3 | Поддерживается сборкой, совместимой с 1.8.2 | Не регистрируется |
| 1.9 | Поддерживается | Unix-время изменения `extended_meta_protocol.ini` |

Сборки AMXX 1.8.2 и 1.8.3 не публикуют значение `em_updated`. Обработчик данных должен трактовать отсутствие поля как «время изменения конфигурации недоступно».

## Установка

1. Скомпилируйте плагин `extended_meta_protocol.sma` компилятором, соответствующим версии AMX Mod X вашего сервера.
2. Скопируйте `extended_meta_protocol.amxx` в `addons/amxmodx/plugins/`.
3. Добавьте следующую строку в `addons/amxmodx/configs/plugins.ini`:

   ```ini
   extended_meta_protocol.amxx
   ```
4. Скопируйте `extended_meta_protocol.ini` в `addons/amxmodx/configs/`.
5. Замените все демонстрационные значения в `extended_meta_protocol.ini`.
6. Смените карту или выполните `em_reload` из консоли с RCON-доступом.

## Пример конфигурации

```ini
; Файл должен быть сохранён в UTF-8. Комментарий занимает отдельную строку.

[meta]
description = "Публичный deathmatch-сервер с турелями"
mod = "Deathmatch"
keywords = "deathmatch,sentrygun"
icon = "https://your-domain.tld/images/server-icon-64x64.png"
map_image = "https://your-domain.tld/maps/{map}.jpg"
voice_languages = "ru,en"
interface_languages = "ru,en"
publish_commands = 0

[links]
site = "https://your-domain.tld"
discord = "https://discord.gg/your-community"

[custom]
season = "summer-2026"
```

Обязательны только `description` и `mod`. Необязательные текстовые поля можно удалить, закомментировать или оставить пустыми в `[meta]`. Если `publish_commands` присутствует, его значение должно быть `0` или `1`. Секции `[links]` и `[custom]` разрешено полностью убрать.

Комментарий распознаётся после удаления окружающих пробелов, если первый символ строки – `;`. Комментарии в конце значения не поддерживаются:

```ini
; Корректный комментарий
icon = "https://your-domain.tld/icon.png"

; Некорректно: комментарий станет частью значения
icon = "https://your-domain.tld/icon.png" ; комментарий
```

## Публикуемые cvar

### Состояние протокола

| Cvar | Значение |
|---|---|
| `em_status` | Версия плагина и состояние публикации в формате `версия-состояние` |
| `em_error` | Пустое значение при успехе либо стабильный код ошибки |
| `em_schema` | Версия схемы метаданных |
| `em_updated` | Время изменения конфига в AMXX 1.9; отсутствует в 1.8.2/1.8.3 |

Примеры `em_status`:

```text
2026.0.15-1
2026.0.15-0
```

Состояния:

- `0` – конфигурация некорректна, прикладные метаданные очищены.
- `1` – конфигурация корректна, метаданные опубликованы.

### Стандартные метаданные

| Cvar | Значение |
|---|---|
| `em_desc`, `em_desc_2`…`em_desc_4` | Части краткого описания |
| `em_desc_parts` | Число опубликованных частей описания |
| `em_mod` | Название игрового режима или мода |
| `em_keywords` | Ключевые слова через запятую |
| `em_icon` | URL рекомендуемой иконки сервера 64×64 |
| `em_map_img` | URL изображения текущей карты после замены `{map}` |
| `em_lang_voice` | Языки общения игроков через запятую |
| `em_lang_ui` | Языки интерфейса сервера через запятую |
| `em_commands`, `em_commands_2`…`em_commands_4` | Опциональные части списка публичных команд AMXX |
| `em_command_parts` | Число частей списка команд |

### Ссылки и пользовательские поля

| Cvar | Значение |
|---|---|
| `em_links` | Список активных ключей ссылок через запятую |
| `em_link_<ключ>` | URL из секции `[links]` |
| `em_custom` | Список активных пользовательских ключей через запятую |
| `em_x_<ключ>` | Нестандартное поле из секции `[custom]` |

Мониторинг должен использовать `em_links` и `em_custom` как авторитетные списки активных полей. Неизвестные `em_x_*` явно считаются нестандартизированными и не должны интерпретироваться как поля спецификации.

После удаления динамического поля из конфига плагин очистит его значение и снимет `FCVAR_SERVER` при следующей смене карты или выполнении `em_reload`. Если ключ вернуть, публикация восстановится.

GoldSrc не позволяет полностью разрегистрировать cvar без перезапуска сервера. После окончательного удаления EMP перезапустите сервер, чтобы гарантированно убрать ранее зарегистрированные cvar из памяти движка.


## Правила URL

URL в `icon`, `map_image` и `[links]` должен отвечать всем требованиям:

- схема `http://` или `https://`;
- непустое DNS-имя хотя бы с одной точкой и одной латинской буквой;
- части домена длиной 1–63 символа из латинских букв, цифр и дефисов;
- часть домена не начинается и не заканчивается дефисом;
- необязательный порт в диапазоне `1–65535`;
- отсутствуют пробелы, управляющие символы, двойные кавычки, обратная косая черта, `<` и `>`.

Литеральные IPv4- и IPv6-адреса, `localhost` и имена без точки отклоняются. Для интернациональных доменов используйте Punycode.

Изображения Base64 не поддерживаются. Используйте URL HTTP(S).

## Обнаружение публичных команд

По умолчанию обнаружение команд отключено. Это экспериментальная функция.

```ini
publish_commands = 0
```

## Рекомендации для мониторингов

- Получайте метаданные через `A2S_RULES`.
- Проверяйте `em_status` до обработки прикладных полей.
- Считайте состояние `0` отсутствием опубликованных метаданных и анализируйте `em_error`.
- Трактуйте отсутствующий `em_updated` как неподдерживаемое поле, а не timestamp `0`.
- Собирайте пронумерованные части по `em_desc_parts` и `em_command_parts`.
- Используйте `em_links` и `em_custom` для определения активных динамических ключей.
- Считайте все строки и URL сервера недоверенными данными.
- Не дублируйте через EMP название сервера, карту, число игроков и ботов, пароль, VAC и версию сервера: эти значения уже присутствуют в стандартных ответах A2S.
